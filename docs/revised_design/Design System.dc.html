01 · Character

A lit desk, not a dashboard

The product connects a learning statement to the line of code that supports it. Everything in the system serves that pairing: planes hold reading, recesses hold code, annotation locates evidence, and the one saturated color means “this is the action.”

02 · Planes and light

Five depths, one light source

Light comes from above. A plane gets a 1px top light and a contact shadow; a recess gets an inner top shadow; a float gets ambient shadow because it truly overlaps. The hairline ring is a box-shadow so it stays crisp at any density and never doubles with a divider.

03 · Color roles

Graphite, teal, and four words

Neutrals carry a trace of green-grey (hue 160, chroma ≈ 0.005) so the workspace feels like one material rather than #222. Teal is action and selection only. Amber locates evidence and is never a verdict. Lilac is the coach’s voice. Result colors keep their semantic roles and always pair with text.

04 · Type roles

Three families, eight roles

Gabarito for the page title and the learning moment: warm, slightly geometric, unmistakably not a system font. Geist for every interface role. Geist Mono for code, line references, and timestamps, so a precise location always looks precise. Local fallbacks: Bahnschrift, Segoe UI, Cascadia Code.

05 · Shape

Radius follows nesting

One radius for everything is what made the old UI read as generated. Now the curve tightens as a surface nests: pane 14 → card 10 → control 8 → inner 6. Circles remain for avatars and point markers. A status doesn’t get a pill by default; it gets a dot and a word.

06 · Controls

Three materials, three weights

Primary is lit teal with a soft glow and dark ink (contrast stays above 4.5:1). Secondary is a raised graphite control with a ring and contact edge. Ghost is a hairline. Quiet is text. Press drops the top light and travels 1px; hover brightens; focus is a 2px teal ring outside the control and always beats material highlights.

08 · Motion

Nothing moves linearly

Decelerate in, accelerate out. Siblings stagger by 40 ms, capped at six. Duration scales with size: 150 press, 200 state, 350 enter, 450 pane. Code and evidence never move; annotation arrives around them. Motion never editorializes: a failing case and a passing case enter the same way. Gates are unchanged: OS preference, in-app preference, pointer input.
