Return the first value you encounter for a second time.

Scan the list from left to right. Return the value as soon as it repeats. If no value repeats, return None.

Example

input[7, 2, 7, 2] output7

The second 7 appears before the second 2, so the answer is 7.

Keep in mind

  • The input may be empty.
  • Scan in the order given; don’t sort the input.
  • Return a value instead of printing it.
Clarifying the requirement

“First” means the earliest qualifying position in a left-to-right scan. Ask about an ambiguity before choosing your approach.
