01 · Launch

Draw-in

Hub first, spokes draw outward clockwise from the top, open nodes pop on as each spoke lands, teal node arrives last. Holds, fades, plots again. Play once on splash and hand off to the loading loop if the wait continues.

3.2s · ease-out
spokes 0→34% · nodes 12→42% · teal 44→58%
hold to 76% · fade 76→88%

02 · Loading

Roadmap fill

The current node stays lit. The five open nodes inflate to teal one after another, clockwise from where you are, each spoke tinting with its node. Once the ring is full it empties in the same order. Below 32px the open nodes are absent, so teal nodes grow from nothing.

3.6s · ease-in-out · stagger 10%
inflate 2.5→5.8→5 over 8% · hold 42%
deflate over 8% · hub kick at 0%

03 · Voice

Equalizer

The spokes are level meters. Each node slides toward the hub and back on its own phase, its spoke shortening with it. The teal node swings furthest. Use whenever the mic is open or the coach is speaking; it can also be driven from live audio levels instead of fixed phases.

1.6s · ease-in-out · sinusoidal
travel 31% of spoke (teal 40%)
phases 0 · −35 · −70 · −15 · −55 · −90%

SequenceDraw-in once on launch → Roadmap fill while data loads → static mark. Equalizer replaces the static mark only while audio is active, and returns to it within one cycle.

GeometryAll three animate the brand-sheet mark unchanged: 48 grid, hub 3.5, nodes 2.5, current node 5, strokes 2 (3.2 at 32 and below, open nodes dropped). Only radius, position and colour move; nothing is redrawn.

FaviconBrowsers don’t play animated SVG favicons. Ship the 16px frames via a small script that draws the mark to a canvas and swaps the icon at ~12fps; stop on blur and restore the static icon.
